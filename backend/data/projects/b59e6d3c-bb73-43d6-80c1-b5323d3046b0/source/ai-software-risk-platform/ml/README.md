# ml/

Reserved for machine-learning code, added in later phases:

- `models/` — trained model artifacts (not committed to Git).
- `datasets/` — dataset loading/versioning utilities.
- `features/` — feature engineering pipelines.
- `preprocessing/` — data cleaning and preprocessing.
- `training/` — model training scripts.
- `evaluation/` — model evaluation and explainability (SHAP).

No ML model is trained and no dataset is invented in Phase 1. See
`docs/roadmap.md` for when this directory becomes active (Phases 2–6).
